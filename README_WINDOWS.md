# CogniLoad — Windows Desktop Application

Turn the CogniLoad web app into a standalone Windows `.exe` installer that users can double-click to install, with no Python, Node.js, or terminal required.

---

## How It Works

```
CogniLoad_Setup_1.0.0.exe
        │
        ▼  (installs to C:\Program Files\CogniLoad\)
  CogniLoad.exe  ──launches──▶  FastAPI backend (uvicorn, port 8000)
        │                              │
        │  (system tray icon)          ▼
        │                       Serves React SPA (pre-built dist/)
        │                              │
        └──opens browser──────────────▶ http://127.0.0.1:8000
```

Everything runs locally on the user's machine. No internet connection required after install.

## Prerequisites (Build Machine — Windows only)

| Tool | Version | Download |
|------|---------|----------|
| Python | 3.11 or 3.12 | https://python.org |
| Node.js | 18+ | https://nodejs.org |

> ⚠️ Build must be done on Windows. PyInstaller produces OS-native binaries.

## Build Steps

### 1. Copy packaging files into your project

Your project root should look like:
```
Cognitive-Load-Detection-main/
├── backend/
├── frontend/
├── ml/
├── cogniload_app.py          ← copy from this package
├── cogniload.spec            ← copy from this package
├── resources/
│   ├── icon.ico              ← auto-generated or replace with your own
│   ├── icon.png
│   └── version_info.txt      ← copy from this package (edit company name)
├── installer/
│   └── setup.iss             ← copy from this package
└── scripts/
    ├── build_windows.bat     ← copy from this package
    └── generate_icon.py      ← copy from this package
```

### 2. Patch the backend `main.py`

The desktop app needs the backend to:
- Serve the React frontend as static files (so no separate Node server)
- Expose a `/health` endpoint the launcher polls on startup

**Option A — Replace** `backend/main.py` with `backend_main_patch.py` (rename it).

**Option B — Merge** the additions from `backend_main_patch.py` into your existing `backend/main.py`:
- Add the `/health` route
- Add the `StaticFiles` mount + SPA catch-all route at the bottom
- Add `load_dotenv(os.environ.get("COGNILOAD_ENV_FILE", ".env"))`

### 3. Run the build script

```bat
scripts\build_windows.bat
```

This automatically:
1. Installs Python packages (`pip install -r backend/requirements.txt`)
2. Builds the React frontend (`npm run build` → `frontend/dist/`)
3. Generates the app icon (if `resources/icon.ico` doesn't exist)
4. Runs PyInstaller → `dist/CogniLoad/CogniLoad.exe`
5. Compiles the Inno Setup installer → `installer/Output/CogniLoad_Setup_1.0.0.exe`

### 4. Distribute

Send users `installer/Output/CogniLoad_Setup_1.0.0.exe`. It's a single file they double-click.

## Manual Build (step by step)

```bat
REM Step 1 — Install dependencies
pip install -r backend\requirements.txt
pip install pyinstaller pystray Pillow

REM Step 2 — Build React frontend
cd frontend
npm install
npm run build
cd ..

REM Step 3 — Generate icon (skip if you have icon.ico already)
python scripts\generate_icon.py

REM Step 4 — Package with PyInstaller
pyinstaller cogniload.spec --noconfirm --clean

REM Step 5 — Create installer (requires Inno Setup installed)
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\setup.iss
```

## What the Installer Does

When a user runs `CogniLoad_Setup_1.0.0.exe`:

1. **Installs** all files to `C:\Program Files\CogniLoad\` (or user-chosen path)
2. **Creates** Start Menu shortcuts
3. **Optionally** creates a Desktop shortcut
4. **Optionally** registers as a startup app (Windows boot)
5. **Optionally** launches the app immediately after install

When the user **launches** `CogniLoad.exe`:

1. Creates `%APPDATA%\CogniLoad\.env` on first run (with sensible defaults)
2. Starts the FastAPI backend on `http://127.0.0.1:8000`
3. Shows a splash screen while the server starts
4. Opens the app in the default browser
5. Adds a system tray icon (right-click → Open / Quit)

## Configuration

On first launch, the app creates `%APPDATA%\CogniLoad\.env`:

```env
DATABASE_URL=sqlite:///C:/Users/<you>/AppData/Roaming/CogniLoad/cogniload.db
SECRET_KEY=<auto-generated>
MODEL_PATH=C:/Program Files/CogniLoad/ml/saved_models/model.joblib
```

Users can edit this file to point to a PostgreSQL database or change the port.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError` after install | Add missing module to `hiddenimports` in `cogniload.spec` |
| Blank browser window | Check backend started; open `http://127.0.0.1:8000/health` manually |
| `pynput` not capturing keys | The collector needs elevated permissions; run as Administrator or adjust UAC settings |
| Antivirus flags the .exe | Expected with PyInstaller — submit to VirusTotal for reputation, or code-sign the binary |
| Port 8000 already in use | Edit `.env` or pass `--port 8080` on the shortcut's target line |

## Code Signing (Recommended for Distribution)

Unsigned `.exe` files will trigger Windows SmartScreen. To remove the warning:

1. Purchase an EV Code Signing certificate (DigiCert, Sectigo, etc.)
2. Sign the PyInstaller output *before* running Inno Setup:
   ```bat
   signtool sign /tr http://timestamp.digicert.com /td sha256 /fd sha256 /a dist\CogniLoad\CogniLoad.exe
   ```
3. Add to `setup.iss`:
   ```ini
   SignTool=mysigntool sign /tr http://timestamp.digicert.com /td sha256 /fd sha256 /a $f
   ```

## Architecture Notes

- **No Node.js required at runtime** — the React app is compiled to static HTML/JS/CSS at build time and served by FastAPI's `StaticFiles`.
- **No Python required at runtime** — PyInstaller bundles the interpreter and all packages.
- **SQLite by default** — zero config, database lives in `%APPDATA%\CogniLoad\`.
- **ML model included** — `ml/saved_models/model.joblib` is bundled; users can retrain via the API.
- **Collector is a separate optional component** — `backend/collector/main.py` can be packaged as a second `.exe` (`CogniLoadCollector.exe`) using the same approach if needed.
